# Lumos Candle 🕯️

A responsive front-end website for **Lumos Candle**, a fictional handcrafted candle brand. 
The project showcases a clean and elegant landing page with information about the brand, featured scents, and a customizable candle order form.

## Features

- Responsive design
- Hero section with product images
- About section
- Popular scents showcase
- Custom candle order form
- Semantic HTML5 structure
- Modern CSS using Flexbox, Grid, and CSS Variables

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Sections

- Header & Navigation
- Hero Banner
- Our Story
- Popular Scents
- Create Your Candle Form
- Footer
